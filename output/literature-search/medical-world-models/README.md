- `final-corpus/included.csv`
- `final-corpus/excluded.csv`

- `screening/prisma-flow-data.json`

Files outside `final-corpus/` preserve developmental searches, screening
passes, provisional extraction, and audit history. They are evidence-trail
artifacts rather than current manuscript inputs unless a canonical file above
explicitly references them.

Human verification and the authenticated-database update remain submission
gates. No artifact in this directory should be represented as a completed
human systematic-review workflow until those gates are closed.
